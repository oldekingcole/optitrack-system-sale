1. Unzip this repository to a normal local folder.
2. Read `GITHUB_DESKTOP_QUICKSTART.md`.
3. Run the bootstrap script for your operating system.
4. Add the folder to GitHub Desktop and publish the repository as private when available.
5. Open the repository in a terminal.
6. Run either `codex` or `claude`.
7. Paste the matching deployment prompt from the repository root.
8. Personally complete authentication, secret entry, domain, DNS, permission, billing, and final-production approvals when prompted.

The agent should operate on the same local Git repository as GitHub Desktop. It does not need to connect to or control GitHub Desktop.
